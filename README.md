# Башня из слоновой кости

Сайт для публикации стихов. Поэты пишут и публикуют стихи, читатели ставят лайки, сохраняют любимое в избранное и подчёркивают строки, которые им понравились. Самые подчёркнутые строки попадают в «Цитатник башни» на главной странице.

## Что умеет сайт

- Регистрация и вход.
- Страница поэта со всеми его стихами.
- Публикация, редактирование и удаление своих стихов, теги, поиск.
- Лайки, избранное и подчёркивание строк прямо в тексте стиха.
- Рейтинг поэтов и «Цитатник башни».
- Критики: пишут рецензии с оценкой от 1 до 10. Роль критика поэт получает автоматически, когда наберёт достаточно очков.
- Админка: список пользователей, смена ролей, удаление.

## Как запустить

Понадобятся Java 21, Maven, PostgreSQL и Tomcat 10.1 или новее.

### Как стать администратором

Зарегистрируйтесь на сайте, а потом выполните в базе:

```sql
UPDATE users SET role = 'ADMIN' WHERE username = 'ваш_логин';
```

## Из чего сделано

Java 21, сервлеты и JSP, PostgreSQL через JDBC, Maven. Без Spring и других фреймворков, оформление на чистом CSS, немного JavaScript.

## Как устроен код

Код разложен по слоям, и запрос проходит их сверху вниз:

`servlets` (страницы и запросы) → `service` (правила и проверки) → `dao` (работа с базой) → PostgreSQL.

Страницы лежат в `src/main/webapp/WEB-INF/views`, стили и скрипты в `src/main/webapp/static`.
